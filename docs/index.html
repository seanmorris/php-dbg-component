Add a PHP debugger
to your page.

Let readers step through examples and edit variables as PHP runs in their browser. Embed it with vanilla JavaScript, or connect an existing editor.

Try the debugger Quickstart

Try it here

PHP 8.0–8.5 · Runs in your browser

Click Run to pause on line 5. Expand $item and change price to 10, then click Continue. The total changes from 24 to 30.

Loading the interface. PHP downloads when you click Run.

PHP runs in a worker. The selected runtime downloads on its first run; components on the same page share binaries and compiled modules.

Use it with your own code

Pass a PHP string, bind a textarea, or attach an Ace or CodeMirror adapter. The optional interface uses ordinary CSS, so it can match your page.

Embedding instructions · Editor adapters

import {PhpDebugger} from 'php-dbg-component';
import 'php-dbg-component/styles.css';

const dbg = new PhpDebugger({
  runtimeBaseUrl: './runtime/',
  code: '<?php\n$n = 2;\n$n += 3;\necho $n;',
  breakpoints: [3]
});
dbg.mount(document.querySelector('#debugger'));

Run PHP tests from the page

Use the same controller to check output and exit codes. Await each result or schedule separate controllers in parallel. Mounting the interface is optional.

Test execution and results

const test = new PhpDebugger({
  runtimeBaseUrl: './runtime/',
  code: '<?php echo 6 * 7, "\\n";'
});
try {
  const result = await test.run({
    mode: 'test',
    expect: {stdout: '42\n', exitCode: 0}
  });
  console.log(result.test.status); // "passed"
} finally {
  await test.destroy();
}
