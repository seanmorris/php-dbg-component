02 / SCRIPTABLE EXECUTION

A page can be a test.

Ordinary promises and structured results let your application decide what runs next. Test mode continues past breakpoints.

const result = await dbg.run({
  mode: 'test',
  expect: { stdout: '42\n', exitCode: 0 },
  timeoutMs: 5000
});
console.log(result.test.status);
Not run yet

Same component. Different role.

Use an async code getter, a textarea, a DOM element, or an editor adapter. Await a run, inspect its result, then schedule the next one however you like.

autorun mode="test" makes visiting a page run a declarative test. Autorun is always explicit.

See a declarative test
<php-debugger autorun mode="test">
  <textarea><?php echo "ok";</textarea>
  <script type="application/json" data-expect>
    {"stdout":"ok","exitCode":0}
  </script>
</php-debugger>

03

Make it yours

Light DOM and ordinary CSS. Use the included stylesheet as a starting point, or give every control your own page's style.

import {PhpDebugger} from 'php-dbg-component';
import 'php-dbg-component/styles.css';

const dbg = new PhpDebugger({
  runtimeBaseUrl: './runtime/',
  code: '<?php\n$n = 2;\n$n += 3;\necho $n;',
  breakpoints: [3]
});
dbg.mount(document.querySelector('#debugger'));

Editing values while paused
const done = dbg.run();
await dbg.whenPaused();
const vars = await dbg.inspect('variables');
await dbg.setVariable(vars.find(v => v.name === 'n').reference, '42');
await dbg.evaluate('$cart["price"] = 12.50');
await dbg.continue();
const result = await done;

Variable references expire on resume. Assignments use PHP expressions in the selected frame, with PHP's normal visibility, types, and readonly rules.

Workers, DOM access, and termination

A worker keeps the page responsive and can be terminated even during a blocking native call. To access the page DOM through vrzno, opt into execution:'main'. Main-thread pause and stop are cooperative, so a blocking native call may block the page. Treat executed PHP as trusted code; workers are not a security boundary.

Loading extensions

Set extensions:['curl'] to load only that version's curl package. The loader uses extension metadata for required libraries and files. Browser CORS still applies to PHP HTTP requests.
